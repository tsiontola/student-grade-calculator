 Student Grade Calculator

 Project Description
A simple web application that calculates the total marks,
average marks, and grade of a student across three subjects.

 Technologies Used
- HTML
- CSS
- JavaScript

 Features
- Enter marks for three subjects
- Calculate total marks
- Calculate average marks
- Display the student's grade
- Validate marks between 0 and 100
- Reset the calculator

 Grading System
- 90–100: A+
- 80–89.99: A
- 70–79.99: B+
- 60–69.99: B
- Below 60: c
- Below 50: F

 How to Run
1. Download or clone the repository.
2. Open index.html in a web browser.
3. Enter marks for three subjects.
4. Click Calculate to see the results.
